O Projekcie

Ten projekt to interaktywny panel edukacyjny poświęcony ochronie przed atakami DDoS (Distributed Denial of Service). Jego celem jest dostarczenie kompleksowej wiedzy na temat tego, czym są ataki DDoS, jak się przed nimi chronić (zarówno dla użytkowników, jak i administratorów stron internetowych) oraz gdzie zgłaszać incydenty.

Panel został zaprojektowany z myślą o nowoczesnym, futurystycznym wyglądzie, aby w przystępny sposób przedstawić złożone zagadnienia cyberbezpieczeństwa.

Funkcjonalności

•
Definicja Ataków DDoS: Zrozumienie podstawowych mechanizmów i celów ataków.

•
Ochrona dla Użytkowników: Praktyczne wskazówki dotyczące unikania bycia częścią botnetu i zwiększania bezpieczeństwa osobistego.

•
Ochrona dla Administratorów: Strategie wielowarstwowej obrony stron internetowych, w tym wykorzystanie CDN, firewalli i rate limiting.

•
Procedury Zgłaszania Ataków: Informacje o tym, gdzie i jak zgłaszać incydenty DDoS, wraz z listą kluczowych instytucji (np. CERT Polska).

•
Interaktywny Interfejs: Łatwa nawigacja między sekcjami dzięki intuicyjnym zakładkom.

Technologie

Projekt został zaimplementowany przy użyciu standardowych technologii webowych:

•
HTML5: Struktura strony.

•
CSS3: Stylizacja i animacje (futurystyczny design).

•
JavaScript: Interaktywność (przełączanie zakładek).

•
Font Awesome: Ikony.

•
Google Fonts: Niestandardowe czcionki (Orbitron, Space Grotesk).

About the Project

This project is an interactive educational panel dedicated to DDoS (Distributed Denial of Service) attack protection. Its goal is to provide comprehensive knowledge on what DDoS attacks are, how to protect against them (for both users and website administrators), and where to report incidents.

The panel is designed with a modern, futuristic aesthetic to present complex cybersecurity topics in an accessible manner.

Features

•
DDoS Attack Definition: Understanding the basic mechanisms and objectives of attacks.

•
User Protection: Practical tips for avoiding becoming part of a botnet and enhancing personal security.

•
Administrator Protection: Multi-layered strategies for website defense, including the use of CDNs, firewalls, and rate limiting.

•
Incident Reporting Procedures: Information on where and how to report DDoS incidents, along with a list of key institutions (e.g., CERT Polska).

•
Interactive Interface: Easy navigation between sections using intuitive tabs.

Technologies Used

The project is implemented using standard web technologies:

•
HTML5: Page structure.

•
CSS3: Styling and animations (futuristic design).

•
JavaScript: Interactivity (tab switching).

•
Font Awesome: Icons.

•
Google Fonts: Custom fonts (Orbitron, Space Grotesk).
